# BMI Calculator 🧮

A simple and beginner-friendly **BMI (Body Mass Index) Calculator** built using Python and Streamlit. This application calculates BMI based on the user's weight and height and displays the corresponding BMI category.

## 🚀 Features

- Calculate BMI using height and weight.
- Display BMI score up to two decimal places.
- Identify BMI categories:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Simple and interactive user interface.

## 🛠️ Technologies Used

- Python
- Streamlit

## 📐 BMI Formula

BMI is calculated using the following formula:

**BMI = Weight (kg) / Height (m)²**

## 📊 BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9 | Overweight |
| 30 or above | Obese |

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/stiwari0223-ux/Bmi-Calculator.git
```

**2. Navigate to the project folder**

```bash
cd Bmi-Calculator
```

**3. Install Streamlit**

```bash
pip install streamlit
```

**4. Run the application**

```bash
python -m streamlit run Bmi.py
```
